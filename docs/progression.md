# La progression

On commence au niveau 1, quelle que soit son expérience : c'est le plus court chemin pour
connaître le projet. On passe au suivant quand le niveau est fait.

**1. Premiers pas**
- [ ] Lancer le backend et le frontend sur ta machine ([TECHNICAL.md](../TECHNICAL.md)).
- [ ] Te connecter à l'admin de Django.
- [ ] Faire merger une première pull request sur une `good first issue`.
- [ ] Noter dans une issue `docs` ce qui t'a surpris ou bloqué en arrivant.

**2. De bout en bout**
- [ ] Faire merger deux pull requests `niveau-2`, chacune avec ses tests.
- [ ] Suivre une donnée du modèle Django jusqu'à l'écran.
- [ ] Relire la pull request d'un autre bénévole et y laisser un commentaire utile.

**3. Confirmé**
- [ ] Faire merger une pull request `niveau-3`.
- [ ] Aider un tech lead à découper une issue.

Niveau 3 fait : tu peux relire des pull requests avec les tech leads.

Les mots du métier (SAR, MRCC, AIS…) sont dans le [glossaire](glossaire.md).
