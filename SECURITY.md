# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/memolabs-dev/mediterranean-rescue/security/advisories/new). Do not open a public issue.

Include what you found, how to reproduce it and what it lets an attacker do. You will get an answer within a week. Please give us a reasonable time to fix the issue before disclosing it.

## Scope

- The application in this repository and the demo at <https://rescue.memolabs.dev>.
- Accounts, invitations, roles and the publication workflow are in scope; so is anything that could publish, change or withdraw an event without the right role.
- Out of scope: denial of service by volume, findings that need a compromised account with the administrator role, and the websites of SOS MEDITERRANEE, CartONG or Data for Good.

Test only against your own local instance or the demo, never with real people's accounts, and stop as soon as you reach data that is not yours.

## Supported versions

Only `main` and the image it publishes are supported.
